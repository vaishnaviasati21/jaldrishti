JalDrishti - Smart Water & Agricultural Monitoring System
As a part of ENVIRONMENTAL SUSTAINABILITY GROUP ACTIVITY
A prototype dashboard that monitors soil moisture, rainfall, water level and humidity, calculates a risk score (LOW / MEDIUM / HIGH) and recommends irrigation actions.
Tech: Python, Tkinter (no extra installs)
Run: python main.py
Note: sensor data is simulated and the logic is rule-based. ESP32 sensor integration is planned.
